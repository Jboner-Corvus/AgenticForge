Voici un prompt complexe pour tester l'agent avec un workflow multi-étapes difficile :

---

**Test Complexe d'Agent - Workflow Multi-Étapes**

Tu es un agent d'automatisation web expérimenté. Je veux que tu exécutes un workflow complexe sur le site https://httpbin.org/forms/post qui teste toutes tes capacités. Voici les étapes à suivre précisément :

**ÉTAPE 1: Navigation et Initialisation**
- Navigue vers https://httpbin.org/forms/post
- Attends que la page se charge complètement
- Prends une capture d'écran de la page d'accueil

**ÉTAPE 2: Remplissage du Formulaire**
- Clique sur le champ "Customer name" et tape "Agent Test Complexe"
- Clique sur le champ "Telephone" et tape "+33-1-23-45-67-89"
- Clique sur le champ "E-mail" et tape "test.complex@agent.ai"
- Sélectionne l'option "Small" dans le menu déroulant de taille
- Coche la case "Pepperoni" et "Extra cheese" pour les toppings
- Tape "Instructions spéciales pour test d'agent complexe" dans le champ commentaires

**ÉTAPE 3: Validation et Capture**
- Prends une capture d'écran du formulaire rempli
- Clique sur le bouton "Submit order"
- Attends que la réponse se charge
- Extrait le contenu JSON de la réponse
- Prends une capture d'écran de la page de résultats

**ÉTAPE 4: Gestion des Tâches**
- Crée une todo "Analyser la réponse du formulaire"
- Crée une todo "Valider les données soumises"
- Crée une todo "Générer un rapport de test"
- Marque la première todo comme "en cours"
- Après 3 secondes, marque-la comme "terminée"
- Fais de même pour les autres todos avec des délais différents

**ÉTAPE 5: Gestion d'Erreurs**
- Essaie de naviguer vers une URL invalide (https://invalid-domain-that-does-not-exist.com)
- Gère l'erreur qui se produit
- Reviens à la page de résultats précédente
- Prends une capture d'écran pour confirmer le retour

**ÉTAPE 6: Analyse et Rapport**
- Extrait toutes les données de la réponse JSON
- Compare les données soumises avec celles reçues
- Génère un rapport détaillé des résultats du test
- Inclut les captures d'écran dans le rapport

**CONTRAINTES IMPORTANTES:**
- Utilise TOUJOURS les outils appropriés pour chaque action
- Prends des captures d'écran à chaque étape majeure
- Gère les erreurs gracefully et continue le workflow
- Respecte les délais entre les actions (utilise des attentes explicites)
- Documente chaque étape avec des commentaires détaillés
- Si une étape échoue, essaie au moins 2 fois avant d'abandonner

**VALIDATION FINALE:**
- Vérifie que toutes les todos sont terminées
- Fournis un résumé complet du workflow exécuté
- Indique le temps total écoulé
- Liste tous les outils utilisés et leur fréquence

Ce test évalue ta capacité à gérer des workflows complexes, la gestion d'erreurs, la coordination d'outils multiples, et la persistance face aux défis.

---

Ce prompt teste l'agent sur :
- Navigation web complexe
- Interactions avec formulaires
- Gestion d'erreurs et récupération
- Coordination de multiples outils
- Gestion de tâches (todos)
- Capture et analyse de données
- Génération de rapports
- Gestion du temps et des délais
